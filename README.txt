# SCI-CA: Scientific Calculator

## Overview
SCI-CA is a simple scientific calculator built using Python and Tkinter. It supports basic arithmetic, trigonometric functions, logarithms, memory storage, and toggling between degrees and radians.

## Features
- Basic operations: Addition, Subtraction, Multiplication, Division
- Advanced functions: `sin`, `cos`, `tan`, `log`, `ln`, `sqrt`
- Memory functions:
  - **M**: Store value
  - **MR**: Recall stored value
- Constants: `π` (Pi), `e` (Euler’s Number)
- Toggle between **Degrees** and **Radians** for trigonometric calculations

## How to Use
1. Click the numeric and operator buttons to enter an expression.
2. Press `=` to evaluate.
3. Use `C` to clear the screen.
4. Click **M** to store the displayed value.
5. Click **MR** to recall stored value.
6. Click **Toggle Degrees/Radians** to switch modes.

## Running the Calculator
Ensure you have Python installed, then run:
```sh
python calculator.py
```

## Requirements
- Python 3.x
- Tkinter (built-in with Python)

This project is open-source and free to use.
